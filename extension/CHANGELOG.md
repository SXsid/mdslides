# Changelog

## 0.1.0

First release.

- Live deck preview in a webview, updating as you type rather than on save.
- Cursor-to-slide sync, so moving the caret moves the deck.
- Export to a standalone HTML file with CSS, viewer script and images inlined.
- Mermaid diagrams, light/dark themes following the editor, and the CLI's full
  keyboard map.
