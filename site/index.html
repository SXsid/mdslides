Engineering Simplicity

Built for engineers, authors, and teams

Intelligent Layout Classification

One image sits beside your text. Two stack vertically. Three arrange into a bento composition, and four become a balanced 2x2 grid. More than four flow cleanly into continuation screens under the same heading without cluttering your view.

Real-Time Live Reload

Built-in filesystem directory watcher pushes updates through Server-Sent Events. Every time you save your Markdown file, your slides reload immediately.

Single Static Binary

Templates, CSS, and modular ES JavaScript scripts are compiled directly into the executable via Go embed. No Node, no dependencies, no external runtime.

Native Mermaid Diagrams

Write flowchart and sequence diagram fences directly in Markdown. mdslides renders them as crisp, resizable SVGs matching your active theme.

GitHub-Flavored Markdown

Support for tables, task lists, strikethrough, blockquotes, code blocks, and nested list structures right out of the box.

Distribution & Setup

Install and start presenting in seconds

One-Line Shell Script

Installs the matching pre-compiled binary for your operating system and architecture directly into your PATH.

curl -fsSL https://raw.githubusercontent.com/SXsid/mdslides/main/install.sh | bash

Go Toolchain

Compile and install the latest tagged binary directly from GitHub using standard Go tooling.

go install github.com/SXsid/mdslides/cmd/mdslides@latest

Build From Source

Clone the repository and build stripped, compact binaries using the included Makefile.

git clone https://github.com/SXsid/mdslides
cd mdslides && make build
mdslides

Turn any Markdown file into a live, presentable browser deck. Zero dependencies. Zero build step.
